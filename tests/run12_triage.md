## Harness notes
- Port 8000 on this machine is held by an unrelated service that answers every path with
  `{"detail":"Not Found"}`. All RUN12 runs use `BASE=http://127.0.0.1:8123` with
  `python -m http.server 8123 --bind 127.0.0.1`. Suites already honour `process.env.BASE`,
  and `_runall.sh` inherits it.
- Several games open on a start card, so a probe must enter the round via
  `go(game, { resume: { mix: true } })` (or `{ resume: true }` for Echo Boos); pass 1 of the
  probe measured start cards by mistake and pass 2 corrected it. Recorded here because the
  same trap will catch the regression suites S1–S13 add.
- `.echo-boo.lit` measurements must wait out the 120ms transition or they read the *pre*-transition
  value; pass 2 was confounded by exactly that and pass 3 re-measured after 400ms.
